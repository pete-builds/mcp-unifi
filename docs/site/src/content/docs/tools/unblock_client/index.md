# `unblock_client`

Unblock a previously-blocked client by MAC.

Side effects:
- Removes the MAC from the controller's user-block list. The client
  can re-associate immediately.
- Mutates controller state. Use dry_run=True to preview the change
  without applying.

## Example

```python
unblock_client(mac="aa:bb:cc:00:00:01")
```

## Parameters

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `mac` | `string` | yes | — | Client MAC address (e.g. ``"aa:bb:cc:00:00:01"``). |
| `controller` | `string` | no | "default" | Name of the UniFi controller to target. Defaults to ``"default"``. |
| `dry_run` | `boolean` | no | false | Preview the change without applying it. Returns the predicted change set. |
