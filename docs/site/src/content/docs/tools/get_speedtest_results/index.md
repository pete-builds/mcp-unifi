# `get_speedtest_results`

List recent speed-test results, newest first.

Side effects: None (read-only).

Returns one record per test with ``time``, ``xput_up``,
``xput_download``, ``latency``, and ``server``.

## Example

```python
get_speedtest_results(limit=10)
```

## Parameters

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `limit` | `integer` | no | 10 | Max number of results to return (default 10, max 1000). |
| `controller` | `string` | no | "default" | Name of the UniFi controller to target. Defaults to ``"default"``. |
