# `list_access_events`

List badge-scan / door events with filters.

Side effects: None (read-only).

Returns events whose timestamp falls inside the last ``hours_back``
hours. ``result`` filters to ``"granted"`` or ``"denied"``; empty
returns both. ``door_id`` narrows to one door.

## Example

```python
list_access_events(hours_back=6, result="denied", limit=20)
```

## Parameters

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `hours_back` | `integer` | no | 24 | Look-back window in hours. Defaults to 24. |
| `result` | `string` | no | "" | Optional ``"granted"`` or ``"denied"`` filter. Empty (default) returns both. |
| `door_id` | `string` | no | "" | Optional door ``id`` filter. Empty returns events across every door. |
| `limit` | `integer` | no | 100 | Maximum events returned. Defaults to 100. |
| `controller` | `string` | no | "default" | Name of the UniFi controller to target. |
